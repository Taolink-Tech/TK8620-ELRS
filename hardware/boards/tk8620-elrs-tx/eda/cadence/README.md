# Cadence Project

This directory contains the Cadence source project for this hardware module.
Open the project in the matching Cadence toolchain to review or modify the
schematic and PCB.

## Design Source

- Cadence 16.6
- [`ELRS-TX-MODULE-V13-20260608.DSN`](ELRS-TX-MODULE-V13-20260608.DSN):
  OrCAD Capture schematic source.
- [`ELRS-TX-MODULE-V13-20260610.brd`](ELRS-TX-MODULE-V13-20260610.brd):
  Allegro PCB layout source.

## Notes

- Manufacturing files are not stored here. Exported manufacturing files are in
  [`../../fabrication/`](../../fabrication/).
- After modifying the project, update the exported schematic and manufacturing
  files.

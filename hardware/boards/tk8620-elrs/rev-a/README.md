# TK8620 ELRS Rev A

This directory contains hardware design files for TK8620 ELRS Rev A.

Use this directory for one validated hardware revision only. If the schematic,
PCB stackup, placement, RF path, power tree, connector pinout, or mechanical
outline changes in a way that affects manufacturing or compatibility, create a
new revision directory.

## Contents

- `eda/`: editable source design project
- `schematics/`: exported schematic documents
- `pcb/`: exported PCB layout review documents
- `fabrication/`: manufacturing outputs derived from the source design
- `mechanical/`: enclosure, outline, and 3D model files
- `images/`: board photos and rendered images
